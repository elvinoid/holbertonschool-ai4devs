3. AI Code Modernization Assistant ✅ (chosen)

## Problem Statement

Developers often struggle to understand and maintain old code. The product
will use AI to explain code, find common problems, and suggest simple ways
to improve and modernize it.

## MVP Features

- Upload or enter source code
- AI explains difficult code sections
- Detect common bugs and risks
- Suggest fixes and improvements
- Generate a simple modernization plan
