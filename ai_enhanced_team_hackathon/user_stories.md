# User Stories

## User Story 1
As a developer, I want to enter or upload source code so that I can analyze it with AI.

## User Story 2
As a developer, I want AI to explain difficult code so that I can understand it faster.

## User Story 3
As a developer, I want AI to identify bugs so that I can find problems in my code.

## User Story 4
As a developer, I want suggested fixes for detected bugs so that I can improve my code.

## User Story 5
As a developer, I want to see security and technical risks so that I can prioritize important issues.

## User Story 6
As a developer, I want AI to suggest modernization steps so that I can improve old code gradually.

## User Story 7
As a developer, I want to save analysis results so that I can review them later.

## User Story 8
As a developer, I want to review AI suggestions before applying changes so that I remain in control of my code.

## User Story 9
As a team lead, I want to view project analysis results so that I can understand the condition of the codebase.

## User Story 10
As a developer, I want to see the severity of identified problems so that I can address high-priority issues first.
