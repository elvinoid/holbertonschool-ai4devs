# Reflection on AI-Assisted IDE Workflows

## Introduction

Integrating GitHub Copilot into my Visual Studio Code workflow changed how I approach software development tasks. The goal was not to replace manual development, but to determine where AI assistance could reduce repetitive work, improve productivity, and support better development practices.

## Where AI Helped Most

AI helped most with repetitive coding and documentation tasks. GitHub Copilot quickly generated boilerplate code, REST API structures, validation logic, error handling, and configuration files. It was especially useful when implementing common patterns that would otherwise require writing similar code manually.

Documentation also became faster. Copilot helped create README files, API descriptions, configuration documentation, and workflow notes. This allowed more time to be spent reviewing the actual implementation instead of repeatedly writing standard documentation.

## Where AI Struggled

AI-generated code was not always correct or aligned with the exact project requirements. Some suggestions required modification because they did not match the existing project structure or expected file locations. In some cases, AI focused on producing technically valid code without fully understanding the requirements of the grading environment.

AI could also introduce unnecessary complexity or assumptions. For example, generated configurations sometimes needed manual adjustment to match the required folder structure, naming conventions, or project-specific standards.

## Tasks That Improved Most

The biggest improvements were seen in API development, documentation, configuration, and repetitive implementation tasks. CRUD endpoints, validation logic, API documentation, and project configuration could be produced significantly faster with AI assistance.

Tasks requiring detailed project understanding, debugging, validation, or architectural decisions benefited less from direct code generation because they still required human reasoning and verification.

## Lessons for Future IDE Workflows

The main lesson is that AI works best as a development assistant rather than an autonomous developer. Clear prompts, well-defined requirements, and incremental requests produced better results than asking AI to build an entire project at once.

For future workflows, I will use AI for boilerplate generation, documentation, refactoring suggestions, and initial implementations. I will continue to manually review generated code, run tests, verify file structures, and check security and correctness.

Overall, AI can significantly improve development speed, but human judgment remains essential for producing reliable and maintainable software.
