# AI-Ready Project Templates

This directory contains two reusable AI-ready project templates.

## Template 1 - React App

**Location:**

`templates/react-app/`

**Purpose:** Frontend React application development.

**AI Configuration:**

`templates/react-app/.copilot-settings.yaml`

**Automation:**

`templates/react-app/automation/tasks.json`

Features:

- React frontend structure
- GitHub Copilot support
- AI-assisted code generation
- ESLint and Prettier
- AI code review
- AI documentation generation

## Template 2 - Backend API

**Location:**

`templates/backend-api/`

**Purpose:** Backend REST API development with Node.js and Express.js.

**AI Configuration:**

`templates/backend-api/.copilot-settings.yaml`

**Automation:**

`templates/backend-api/automation/tasks.json`

Features:

- Node.js and Express.js
- GitHub Copilot support
- AI-assisted code generation
- ESLint and Prettier
- AI code review
- AI API documentation generation
