# Frontend App Template with AI Support

## Features

- Modern frontend project structure
- GitHub Copilot-ready configuration
- ESLint and Prettier guidance
- AI code review workflow
- AI documentation generation workflow
- Component and accessibility guidelines

## AI Support

GitHub Copilot can assist with:

- UI component generation
- Form validation
- API integration
- Accessibility improvements
- Refactoring
- Testing
- Documentation

## Automation

The `automation/` directory contains reusable AI workflows for:

1. Frontend code review
2. Component documentation generation

## Usage

Copy this template when starting a new frontend application and customize the configuration for the project's requirements.
